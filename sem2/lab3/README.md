# Лабораторная работа №3 — Spring Security

## Описание

В лабораторной работе реализовано веб-приложение на Spring Boot для управления списком задач с использованием Spring Security и Thymeleaf.

Приложение позволяет:
- просматривать список задач;
- добавлять новые задачи;
- удалять задачи;
- отмечать задачи как выполненные;
- отменять выполнение задачи;
- выполнять аутентификацию пользователя с помощью Spring Security.

## Используемые технологии

- Java 17
- Spring Boot 4.1.1
- Spring MVC
- Spring Security
- Thymeleaf
- Maven

## Структура проекта

Основные классы приложения находятся в `src/main/java/ru/bsuedu/cad/lab3/`:

- `Lab3Application.java` — запуск Spring Boot приложения.
- `Task.java` — модель задачи.
- `TaskRepository.java` — хранение и управление списком задач.
- `TaskService.java` — сервисный слой.
- `TaskController.java` — обработка HTTP-запросов.

Шаблон страницы находится в `src/main/resources/templates/index.html`.

## Запуск приложения

Открыть терминал в папке проекта и выполнить:

```powershell
.\mvnw.cmd spring-boot:run
```

После запуска приложение доступно по адресу `http://localhost:8080/`.

## Авторизация

В проект подключён Spring Security. При запуске Spring Boot автоматически создаёт пользователя и выводит сгенерированный пароль в консоль.

- логин: `user`
- пароль: сгенерированный Spring Security пароль из консоли запуска.

## Работа с задачами

На главной странице можно:

1. Добавить новую задачу, указав название и описание.
2. Удалить существующую задачу.
3. Нажать «Выполнить», чтобы отметить задачу выполненной.
4. Нажать «Отменить выполнение», чтобы вернуть задачу в невыполненное состояние.

## Проверка

Работа приложения была проверена локально:

- главная страница успешно открывается после авторизации;
- задача отображается в списке;
- добавление задачи работает;
- удаление задачи работает;
- изменение статуса выполнения работает.
