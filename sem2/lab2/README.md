# Лабораторная работа №2 --- Spring

## Тема

Разработка простого Web-приложения для управления задачами (To-Do List)
с использованием Spring MVC и Thymeleaf.

## Цель работы

Получить практические навыки создания Web-приложений на Spring MVC,
работы с контроллерами, сервисным слоем, репозиторием, моделью данных и
шаблонами Thymeleaf.

## Используемые технологии

-   Java 17
-   Spring Boot 4.1.1
-   Spring MVC
-   Thymeleaf
-   Maven
-   Apache Tomcat
-   IntelliJ IDEA / Visual Studio Code

## Структура приложения

В приложении используются следующие основные классы:

-   `Task` --- модель задачи. Содержит идентификатор, название, описание
    и статус выполнения.
-   `TaskController` --- контроллер, обрабатывающий запросы
    Web-интерфейса.
-   `TaskService` --- сервисный слой, содержащий операции над задачами.
-   `TaskRepository` --- слой хранения списка задач.
-   `index.html` --- HTML-шаблон Thymeleaf для отображения списка задач
    и работы с ними.

## Возможности приложения

Web-приложение позволяет:

1.  Просматривать список задач.
2.  Добавлять новые задачи.
3.  Удалять задачи.
4.  Изменять статус задачи на «Выполнена».
5.  Возвращаться на главную страницу после выполнения операции.

## Запуск приложения

Открыть терминал в корневой папке проекта `lab2` и выполнить:

``` powershell
.\mvnw.cmd spring-boot:run
```

После успешного запуска приложение доступно по адресу:

``` text
http://localhost:8080/
```

## Проверка работы

После открытия страницы отображается заголовок «Список задач» и форма
добавления новой задачи.

Пример задачи:

-   Название: `Изучить Spring MVC`
-   Описание: `Выполнить лабораторную работу 2`

После добавления задача появляется в списке.

Для изменения состояния задачи используется кнопка `Выполнить`. После
нажатия статус задачи изменяется с «Не выполнена» на «Выполнена».

Также доступна ссылка `Удалить`, которая удаляет выбранную задачу из
списка.

## Результат

В результате лабораторной работы разработано работающее Web-приложение
для управления задачами. Реализованы отображение списка задач,
добавление, удаление и изменение статуса выполнения задач через
Web-интерфейс.

Приложение успешно запускается на локальном сервере `localhost:8080`.
